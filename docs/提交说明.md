## 3. 老师/同学复核代码

```bash
git clone https://github.com/libo-zhu/sense-course.git
cd sense-course
uv sync --locked
uv run --locked python scripts/offline_demo.py --device auto
```

这一步不下载数据，验证模型、JAD反向传播、冻结、单输入推理与保存重载。不将合成数据演示作为准确率结果。

真实数据与最佳权重检查：

```bash
uv run --locked python scripts/prepare_data.py
uv run --locked python infer_saved.py --model msh-hsi --device mps --limit 64
uv run --locked python infer_saved.py --model msh-hsi --device mps --limit 0
```

`--limit 0`使用完整官方测试集。CPU可把设备换成`cpu`。原始大数据不放入提交压缩包或Git；下载地址、尺寸与处理方式在README说明。


## 5. 本次方法、结果与学术来源

MSH-Net来自Wei等人的论文与MIT作者代码；S2FL提供公开数据；随机模态丢弃借鉴Neverova等人的ModDrop思想。本次的课程改动是将样本级随机丢弃加入同一多分支特征融合训练，并系统比较缺失组合和噪声，不宣称发明原始ModDrop。

本地MSH仅HSI/SAR/DSM的OA为89.59/80.48/75.41%，HSI与DSM相对单模态OA分别提高0.30与0.72个百分点，完整教师较最佳单模态提高2.41个百分点。报告披露训练点数量、缺少翻转、融合实现、模型选择、邻域重叠和单seed限制。完整数值与评价条件一并列示，便于复核方法在不同输入下的表现。

参考文献、上游commit、许可证与数据条件分别保留。自动化工具辅助代码适配、图表与文字整理，署名成员按交付责任核对并承担内容责任。
